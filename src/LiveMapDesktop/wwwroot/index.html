⌨ Keyboard Shortcuts

Map Navigation

  • Arrow Keys — Pan map
  • + − — Zoom in / out
  • Double-click — Zoom in at point
  • Scroll wheel — Zoom

Mode Toggles

  • F — Toggle follow mode
  • B — Toggle biome overlay
  • S — Toggle structures
  • G — Toggle chunk grid
  • H — Toggle feature panel
  • E — Expand / exit fullscreen map

Markers & Interaction

  • Right-click on map — Place custom marker
  • Click structure marker — View details
  • Esc — Close modals / clear search
  • Enter in seed field — Load seed

Version & Dimension

  • Use the top bar to select Java or Bedrock, then a specific version
  • Structure availability varies by version — the feature panel filters automatically
  • Dimension selector changes which structures and biomes are shown
